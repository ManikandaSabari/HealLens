# 🩺 HealLens AI

HealLens AI is a full-stack, AI-powered healthcare assistant that helps users analyze medical images and medical reports while securely storing their analysis history. The application is designed with a modern web interface, Express.js backend, and Supabase cloud database.

---

## 🚀 Features

- 🫁 AI-based Medical Image Analysis
- 📄 Medical Report Analysis
- 📚 Analysis History
- 🚨 Emergency SOS Contacts
- 🌐 Multilingual Support
- 📱 Android App (Capacitor)
- ☁️ Cloud Database (Supabase)
- 🔒 Secure Backend APIs
